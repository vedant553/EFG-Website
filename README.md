# Eight Fold Group

A premium, fully responsive static website for a luxury civil and landscape construction firm. The website showcases the company's philosophy, vast array of services, and past projects using high-quality aesthetics, immersive CSS animations, and seamless responsive design.

## Features
- **Premium Aesthetics**: High-end typography (Cormorant Garamond & Inter), dark mode overlays, and gold accenting.
- **Fully Responsive**: Flawless experience across Desktop, Tablet, and Mobile.
- **Scroll Animations**: Uses `IntersectionObserver` (Vanilla JS) to reveal elements gracefully as they scroll into view.
- **Bento & Split Grids**: Asymmetrical grid layouts built purely with CSS Grid and Flexbox.
- **Infinite Marquee**: Client logo scroller implemented using CSS keyframes.
- **SEO Optimized**: Includes LocalBusiness and Service `JSON-LD` schemas for superior search engine visibility.

## Technologies Used
- **HTML5**: Semantic markup and schema.org integration.
- **Vanilla CSS**: Custom design system, CSS Grid/Flexbox, and keyframe animations (No frameworks like Tailwind or Bootstrap).
- **Vanilla JavaScript**: Lightweight scroll observation and counting animations.
- **FontAwesome**: Scalable vector icons.

## Running Locally
This project is completely static. No build steps or package managers are required.

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/eight-fold-group.git
   ```
2. Open `index.html` in your favorite web browser.
